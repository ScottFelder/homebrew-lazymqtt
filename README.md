# homebrew-lazymqtt

Homebrew tap for [LazyMQTT](https://github.com/ScottFelder/lazymqtt) — a fast,
keyboard-driven terminal UI MQTT client, inspired by MQTT Explorer.

## Install

```bash
brew tap scottfelder/lazymqtt
brew trust scottfelder/lazymqtt   # Homebrew requires trusting third-party taps
brew install lazymqtt
```

`Formula/lazymqtt.rb` is updated automatically by LazyMQTT's release workflow on
each new version — please don't edit it by hand.
